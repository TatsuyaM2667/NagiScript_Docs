基本概念

変数、型、制御構文の基礎を学びます。

変数と定数

不変変数 (val)

filename.ngs
val x: i32 = 10
val name: str = "NagiScript"
val pi: f64 = 3.14159

val で宣言された変数は再代入できません。

可変変数 (var)

filename.ngs
var counter: i32 = 0
counter = 10  // OK
counter += 1  // OK

型推論

型を省略すると自動推論されます：

filename.ngs
val x = 10        // i32 と推論
val name = "Hello" // str と推論
val flag = true    // bool と推論

文字列型

filename.ngs
val s1: str = "Hello, World!"

val greeting = "Hello, " + "World!"

val len = greeting.len()

真偽値型

val flag2 = false

単型 (Unit)

filename.ngs
val nothing: void = void

制御構文

if 式

NagiScript の if は式です。戻り値を持ちます。

filename.ngs
val x = 10

val result = if x > 5 {
    "大きい"
} else {
    "小さい"
}
// result = "大きい"

for ループ

for ループは範囲構文のみ対応しています：

filename.ngs
// 基本構文
for i in 0..5 {
    io.println(i)
}
// 出力: 0, 1, 2, 3, 4

// step を指定
for i in 0..10 step 2 {
    io.println(i)
}
// 出力: 0, 2, 4, 6, 8

while ループ

filename.ngs
var i = 0
while i < 5 {
    io.println(i)
    i += 1
}

match 式（パターンマッチング）

filename.ngs
val x = 2

val result = match x {
    1 => "one",
    2 => "two",
    3 => "three",
    _ => "other"
}
// result = "two"

ブロック

filename.ngs
val result = {
    val a = 10
    val b = 20
    a + b
}
// result = 30

型変換

隠示的変換 (i64 → i32)

filename.ngs
val a: i64 = 100
val b: i32 = a  // OK: i64 から i32 へ安全な縮小

型注釈による変換

filename.ngs
val x: i32 = 42
val y: f64 = x  // OK: i32 から f64 への拡張

文字列操作

filename.ngs
val s = "Hello"

// 長さ
val len = s.len()  // 5

// 接続
val greeting = s + ", World!"

// 比較
val eq = s == "Hello"  // true
