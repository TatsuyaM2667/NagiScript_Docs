基本概念

変数、型、制御構文の基礎を学びます。

変数と定数

不変変数 (val)

filename.ngs
val x: i32 = 10
val name: string = "NagiScript"
val pi: f64 = 3.14159

val で宣言された変数は再代入できません。

可変変数 (var)

filename.ngs
var counter: i32 = 0
counter = 10  // OK
counter += 1  // OK

型推論

型を省略すると自動推論されます：

filename.ngs
val x = 10        // i32 と推論
val name = "Hello" // string と推論
val flag = true    // bool と推論

文字列型

現行仕様（v0.2.0）

型名は str ではなく string です。文字列の + による連結は未実装なので、"Hello, " + "World!" はコンパイルエラーになります。

filename.ngs
val s1: string = "Hello, World!"
val s2 = "型推論でもOK"

// 文字列同士は比較できる
val eq = s1 == s2  // false

真偽値型

filename.ngs
val flag1: bool = true
val flag2 = false

// 論理演算は && / || / !（キーワード and / or / not は使えない）
if flag1 && !flag2 {
    println("ok")
}

Unit 型について

現行仕様（v0.2.0）

式としての単型 void（val x: void = void のような書き方）は現行では使用できません。戻り値のない関数は fn name() { ... } と書き、-> void は付けません。

制御構文

if 文

現行仕様（v0.2.0）

if は文として使うのが確実です。式として値を返す val x = if ... { } else { } のような使い方は現行ではサポートされていません（ブロック末尾の暗黙 return も不可）。

filename.ngs
var result = ""
if x > 5 {
    result = "大きい"
} else {
    result = "小さい"
}

for ループ（既知バグあり）

現行仕様（v0.2.0）

for i in 0..5 { } はループ本体が IR から落ちて何も実行されない既知バグがあります。また step は未実装です。当面は while を使用してください。

filename.ngs
// 既知バグのため推奨しない（body が実行されない）
// for i in 0..5 { println(i) }

// 代わりに while を使う
var i = 0
while i < 5 {
    println(i)
    i = i + 1
}
// 出力: 0, 1, 2, 3, 4

while ループ

filename.ngs
var i = 0
while i < 5 {
    println(i)
    i = i + 1
}

// 無限ループ（loop キーワードは無い）
while true {
    // ...
}

match（パターンマッチング）

現行仕様（v0.2.0）

パターンは裸の列挙バリアント名（例 Ok, NotFound）と、ワイルドカード _ です。enum の値を生成するときは Status.Ok() のように括弧が必要です。

filename.ngs
enum Status { Ok NotFound }

fn show(s: Status) {
    val st = match s {
        Ok => "200",
        _ => "404",
    }
    println(st)
}

fn main() {
    show(Status.Ok())
}

ブロック

現行仕様（v0.2.0）

ブロック末尾の式を値として返す「式ブロック」（val x = { ... a + b }）はサポートされていません。文としてのみ使用できます。

filename.ngs
// 文ブロック（スコープを区切る目的で使用）
{
    val a = 10
    val b = 20
    val c = a * b
}

型変換

隠示的変換 (i64 → i32)

filename.ngs
val a: i64 = 100
val b: i32 = a  // OK: i64 から i32 へ安全な縮小

型注釈による変換

filename.ngs
val x: i32 = 42
val y: f64 = x  // OK: i32 から f64 への拡張

文字列操作

現行仕様（v0.2.0）

文字列の連結 s + "..." は未実装ですし、s.len() のようなメソッドも現行では定義されていません。文字列は == / != での比較が可能です。

filename.ngs
val s = "Hello"

// 比較
val eq = s == "Hello"  // true
val ne = s != "World"  // true

// 表示
println(s)
