関数

関数の定義と呼び出しを学びます。※モジュール分割（import）は現行では未実装のため、本ページ末尾にロードマップとしてまとめます。

現行仕様（v0.2.0）

戻り値の型は fn name(...) -> 型 の-> 構文です。-> を省略した書き方は動きません。またブロック末尾の暗黙 return（式ブロック）は非対応なので、必ず return を明示してください。

関数の定義

戻り値あり

filename.ngs
fn add(a: i32, b: i32) -> i32 {
    return a + b
}

戻り値なし

戻り値がない場合は -> を書きません（-> void は不可）。

filename.ngs
fn greet(name: string) {
    println(name)
}

引数なし・文字列を返す

filename.ngs
fn get_version() -> string {
    return "1.0.0"
}

関数の呼び出し

filename.ngs
val result = add(10, 20)   // 30
greet("Alice")              // Alice
val ver = get_version()     // "1.0.0"
println(result)

再帰関数

filename.ngs
fn factorial(n: i32) -> i32 {
    if n <= 1 {
        return 1
    }
    return n * factorial(n - 1)
}

val result = factorial(5)  // 120
println(result)

エクスポート（Wasm / C 連携）

現行仕様（v0.2.0）

export は関数宣言の前置にのみ使えます。export "C" fn ... の形を書き、Wasm や C ABI から呼び出せるようにします。変数を export する「export 文」は使えません（export fn ... は誤り）。

utils.ngs
// utils.ngs
export "C" fn add(a: i32, b: i32) -> i32 {
    return a + b
}

export "C" fn multiply(a: i32, b: i32) -> i32 {
    return a * b
}
bash
# WebAssembly 向けにビルド（外部から add / multiply を呼べる）
nagiscript wasm utils.ngs -o utils.wasm

関数型・クロージャは未対応

ロードマップ（未実装）

関数を値として扱う「関数式」（val f = fn(x) { ... }）、関数型フィールド（handler: fn(...)）、高階関数、クロージャは現行ではサポートされていません（不安定）。関数の動的切り替えが必要な場合は、enum のバリアントを match + if で分岐して実装してください。

filename.ngs
enum Op { Add Sub }

fn apply(op: Op, a: i32, b: i32) -> i32 {
    match op {
        Add => return a + b,
        Sub => return a - b,
    }
}

val result = apply(Op.Add(), 10, 5)  // 15
println(result)

メソッド（impl ブロック）

現行仕様（v0.2.0）

メソッドは impl ブロックで定義します。文字列組み込みの s.len() / s.to_upper() のようなメソッドは現行では定義されていません。※ impl と self の詳細は「構造体と列挙型」を参照してください。

filename.ngs
struct Counter {
    n: i32,
}

impl Counter {
    fn incr(self: Counter) -> Counter {
        return Counter { n: self.n + 1 }
    }
}

fn main() {
    val c = Counter { n: 1 }
    val c2 = c.incr()
    println(c2.n)  // 2
}
