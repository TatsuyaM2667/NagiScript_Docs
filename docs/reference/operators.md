# 演算子リファレンス

NagiScript の演算子全体を解説します。

---

## 算術演算子

| 演算子 | 説明 | 例 | 結果 |
|--------|------|-----|------|
| `+` | 加算 | `5 + 3` | `8` |
| `-` | 減算 | `5 - 3` | `2` |
| `*` | 乗算 | `5 * 3` | `15` |
| `/` | 除算 | `5 / 3` | `1` (整数除算) |
| `%` | 剰余 | `5 % 3` | `2` |

### 浮動小数点の除算

```ngs
val a: f64 = 5.0
val b: f64 = 3.0
val result = a / b  // 1.66666...
```

## 比較演算子

| 演算子 | 説明 | 例 | 結果 |
|--------|------|-----|------|
| `==` | 等しい | `5 == 5` | `true` |
| `!=` | 等しくない | `5 != 3` | `true` |
| `<` | 小さい | `5 < 3` | `false` |
| `>` | 大きい | `5 > 3` | `true` |
| `<=` | 以下 | `5 <= 5` | `true` |
| `>=` | 以上 | `5 >= 3` | `true` |

## 演算子の優先順位

| 優先順位 | 演算子 | 説明 |
|----------|--------|------|
| 1 (最高) | `()` | 括弧 |
| 2 | `!`, `not` | 否定 |
| 3 | `*`, `/`, `%` | 乗算、除算、剰余 |
| 4 | `+`, `-` | 加算、減算 |
| 5 | `<`, `>`, `<=`, `>=` | 比較 |
| 6 | `==`, `!=` | 等値比較 |
| 7 | `and` | 論理AND |
| 8 | `or` | 論理OR |
| 9 | `=` | 代入 |
