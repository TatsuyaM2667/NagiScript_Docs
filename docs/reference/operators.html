演算子リファレンス

NagiScript の演算子全体を解説します。

現行仕様（v0.2.0）

このページは現行コンパイラー v0.2.0 の正仕様に合わせてあります。論理演算は && / || / ! を使用します。and / or / not のキーワード、文字列の + 連結、?（エラー伝播）は未実装・使えません。

浮動小数点の除算

main.ngs
val a: f64 = 5.0
val b: f64 = 3.0
val result = a / b  // 1.66666...
現行仕様（v0.2.0）

算術演算子（+ - * / %）は数値に対してのみ動作します。文字列の + 連結は使えず、"Hello" + " World" はコンパイルエラーになります。

現行仕様（v0.2.0）

論理演算には && / || / ! を使用します。and / or / not のキーワードは未実装で、true and false のような書き方はコンパイルできません。

main.ngs
val a = true && (5 > 3)
val b = !false
println(a)
println(b)

ポインタ演算子

演算子説明例
&&アドレス取得val ptr = &&x as *i32
*参照外し（unsafe ブロック内）unsafe { *ptr }
->戻り値型の記法（関数定義のみ）fn f() -> i32
現行仕様（v0.2.0）

ポインタは *T 形式、アドレス取得は &&x as *T、参照外しは unsafe { *ptr } を使います。.offset(n) や ptr->（ポインタ経由のメンバアクセス）は未対応で、*ptr と整数演算で代替してください。

main.ngs
fn read(ptr: *i32) -> i32 {
    unsafe { return *ptr }
}
var x = 42
val p = &&x as *i32
println(read(p))

補足

loop は存在せず、void 型もありません。戻りのない関数は -> を書かず、無限ループは while true { ... } を使います。

文字列演算子

演算子説明例
+文字列連結"Hello" + " World"
現行仕様（v0.2.0）

文字列の + 連結は使えません。"Hello" + " World" はコンパイルエラーになります。文字列は print / println でそのまま表示し、複数の値を並べたい場合は個別に println を呼び出してください。

main.ngs
println("Hello")
println(" World")

リスト演算子

演算子説明例
[]インデックスアクセスlist[0]
+リスト結合list1 + list2
現行仕様（v0.2.0）

List<T> は LLVM コード生成で zext i64 to i64 エラーになりリンクに失敗する既知バグがあります。当面は構造体 + 値渡しを推奨します。またインデックスアクセスの [] 演算子は、固定配列 [T; N] に対して安全に使えます。

その他（未実装の演算子・型）

ロードマップ（未実装）

タプル（(1, 2, 3)、t.0）は未実装/未検証です。関数式（fn(x: i32) i32 { ... }）や関数型フィールド（handler: fn(Request) Response）は現行では不安定で、ルーターは handler_id: i32 と if 分岐で実装してください。void 型も存在しません。
